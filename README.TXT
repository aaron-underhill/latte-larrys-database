All code present in this project is based on the CS 340 starter code, with the exception of the CSS code
and, obviously, the img files. Though we have made slight changes to the code in order to adapt it to our 
own database specifics, overall, the code is fairly identical to the starter code, and we report this as such.
Files that used/relied on starter code includes: all handlebar files, app.js, db-connector.js 

Here is just a listing of where the different files received the majority of their starter code from. 

-Handle Bar Files: Code adapted from nodejs-start-app from course github to fit our database, specifically step 3. 

-Javascript Files: Code adapted from nodejs-start-app from course github to fit our database, specifically step 4-8
(with the exception of app.js, where we've received starter code from step 3 and 8).

As mentioned, the files that are completely original are the CSS and IMG files. All other files utilized starter codes
and were adjusted as needed.
